# Milestone 3 — leakage-safe features, temporal split, and baselines

Generated by `chp baselines`. Every figure is computed from `data/processed/predictions.parquet`; none is transcribed by hand.

## Read this first: the target is part-knowable by construction

The target decomposes exactly — verified to machine precision over 8,727 rows —

```text
target_dg(t) = 100*ln( P(t+3) / P(t) )  -  100*ln( P(t-9) / P(t-12) )
             =        f(t)              -        b(t)
```

where `P` is `price_smoothed`. `f(t)` is the forward three-month growth and is unknown at prediction time. `b(t)` — the **base effect** — already happened, between `t-12` and `t-9`, and is fully observable when the forecast is made.

On the test window `corr(target_dg, -b)` is **0.707**, so roughly half the target's variance is knowable in advance for reasons that have nothing to do with forecasting a housing market. Two consequences run through this report:

1. The magnitude bar is **`base_effect`**, not `zero_change`. Skill against zero-change is reported too, but it credits a model for arithmetic it did not do.
2. `corr_forward` — the correlation between predicted and actual `f(t)` — is the honest measure of forecasting skill. `corr_dg` is inflated because both sides share the `-b` term. The `base_effect` baseline scores `corr_forward` near **zero** by construction, which is what makes the diagnostic trustworthy.

## The split

```text
split:
  train       6,271 rows  2014-03 to 2023-11     117 months  54 counties  35.3% / 31.5% / 33.2%
  validation    486 rows  2024-03 to 2024-11       9 months  54 counties  37.4% / 33.3% / 29.2%
  test          648 rows  2025-03 to 2026-02      12 months  54 counties  36.7% / 36.4% / 26.9%
  embargoed 324 rows at the boundaries; 2,305 rows ineligible
```

Each boundary carries a three-month embargo, one forecast horizon, so no training label resolves inside the validation window and no validation label inside the test window. Hyperparameters were chosen on validation; the chosen configurations were refit on train + validation; the test split was scored once.

## What these results can and cannot claim

**Can.** Both learned models beat their naive counterparts on a genuinely untouched holdout, under a split whose boundaries were frozen before any model was fitted and with a three-month embargo at each boundary. Ridge's advantage survives netting out the mechanical base effect, and its `corr_forward` is well clear of the `base_effect` baseline's near-zero score, so it knows something about the part of the target that had not yet happened.

**Cannot.** These are pooled cross-county results over a single twelve-month test window in one regime; the month-block intervals show how much that window matters. Performance in the thin tier is materially worse than in the large tier and should be read separately. Redfin revises recent months, so the most recent test labels may shift in a later vintage — a look-ahead risk no split can remove. And a single held-out window is not robust temporal validation; that is Milestone 5.
